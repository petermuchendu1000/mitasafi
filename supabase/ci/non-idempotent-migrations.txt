# Migrations that cannot be re-applied over an already-migrated database.
#
# Measured, not guessed: PostgreSQL 16, bootstrap + a from-scratch apply of the
# whole tree, then every migration replayed in filename order.
#
# These are legacy. The failures are CREATE POLICY without a preceding drop,
# ADD CONSTRAINT without IF NOT EXISTS, ALTER PUBLICATION ADD TABLE for a table
# already published, CREATE OR REPLACE VIEW with a changed column order, and a
# couple of guards that assert against state a later migration legitimately
# changed.
#
# scripts/ci/check-migration-idempotency.mjs fails if a migration NOT listed
# here stops being replayable, and also fails if one listed here starts
# replaying cleanly -- so the list can only shrink, and only deliberately.
#
